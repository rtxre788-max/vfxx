# vfxx
CYBERA — центр цифровой безопасности для проверки угроз до перехода по ним. Сервис проводит эвристическую оценку URL на признаки риска без открытия сайта, проверяет файлы по локальному хешу SHA-256 и сканирует содержимое QR-кодов. Также доступны семейная защита с проверкой номеров и демо-оповещениями, встроенный ИИ-помощник
